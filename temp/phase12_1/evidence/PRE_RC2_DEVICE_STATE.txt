--- DATA THAT WILL BE DESTROYED BY THE RC1 UNINSTALL (guide §23 step 4) ---
RC1 is debug-signed and RC2 is signed with the permanent private-alpha key. Android
refuses an update across a signer change, so RC1 must be uninstalled. `pm uninstall`
removes BOTH the internal data dir and the app's external files dir. Lost:

1. SQLCipher-encrypted Room database (internal) — all scan history and findings.
2. Hash-chained audit log (internal) — the entire Phase 2 audit chain on this device.
   NOTE: the chain is per-install by design; a fresh install legitimately starts a NEW
   chain from genesis. This is data loss, not chain tampering.
3. ConfigStore preferences (internal) — execution mode, onboarding state, grants.
4. /sdcard/Android/data/com.thraksha.guardian/files/models/gemma-4-E2B-it.litertlm
   (2.4 GiB) — the external files dir is deleted with the package.
